# Archaeological Site Exploration System

## About the Project

The Archaeological Site Exploration System is a Data Structures micro-project based on the archaeological site of Hampi.

The project represents different locations of Hampi as nodes of a graph and the paths between them as edges. It demonstrates graph traversal and searching concepts using C++.

## Objectives

- Represent an archaeological site using a graph.
- Display locations and their connections.
- Search for a particular location.
- Demonstrate BFS traversal.
- Demonstrate DFS traversal.
- Provide a simple interactive website for project demonstration.

## Data Structures Used

## How to Run the C++ Program

1. Open `main.cpp`.
2. Compile the program using any C++ compiler or online C++ compiler.
3. Run the program.
4. Select an option from the menu.
5. Test searching, BFS and DFS.
